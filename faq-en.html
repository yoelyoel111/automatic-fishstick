How do I create precise stickers with specific dimensions?

+

Use the "Precision Sticker" tool:

  1. Click the "Precision Sticker" button (green button)
  2. Upload your image
  3. Set the desired dimensions in cm (width and height)
  4. Select the crop area from the image
  5. Click "Apply" to create the sticker

Tip: Use printer calibration for maximum precision!

🎯

What is printer calibration and why is it important?

+

Printer calibration ensures stickers print at exact dimensions:

  • Every printer prints slightly different from the required size
  • Calibration corrects this difference
  • Ensures precision up to a millimeter

How to calibrate: Click "Printer Calibration", print the calibration sticker, measure it and enter the result.

🎲

How does the name lottery work? Is it truly random?

+

Yes! The lottery is completely random:

  • The system uses an advanced random algorithm
  • Every name has an equal chance of winning
  • No way to predict or influence the result
  • The lottery runs on your computer (not on a server)

How to use: Enter a list of names, choose how many winners and click "Draw".

📐

How do I determine how many stickers fit on a page?

+

You have full control over sticker layout:

  • Sticker Size: Choose "by width" or "by height"
  • Number of Stickers: Set how many stickers per row/column
  • Margins: Set distance from page edge
  • Spacing: Set distance between stickers

Tip: The system shows you a preview of the layout!

💾

How do I save my project for future use?

+

You have several saving options:

  • Local Save: Click "Save Project" - saves as JSON file
  • Google Drive: Connect to Google account and click "Save to Drive"
  • Auto Backup: System automatically saves in browser

To Load: Click "Load Project" or select from Drive project list.

🖨️

Which format is best for printing - PDF or image?

+

PDF is the recommended format for printing:

✅ PDF - Recommended

  • Professional print quality
  • Preserves exact proportions
  • Compatible with all printers
  • Small file size

📷 Image - For Editing

  • Good for further editing
  • Social media sharing
  • Quick viewing
  • Larger file size

Recommendation: Use PDF for printing and PNG for editing or sharing.

🎨

How do I add text and images to stickers?

+

There are advanced editing tools:

📝 Adding Text:

  • Go to "Text" tab in editing tools
  • Enter the desired text
  • Choose color, size and position
  • Option for automatic numbering

🖼️ Adding Images:

  • Go to "Image" tab in editing tools
  • Upload image from computer
  • Resize and reposition
  • Adjust transparency
🌐

Does the site work without internet connection?

+

Yes! The site supports offline work:

  • Download offline version: Click "Download Offline Version"
  • Local processing: All processing is done on your computer
  • No server needed: Everything works in the browser
  • Full privacy: Your files are not sent anywhere

Note: Internet connection is only needed for Google Drive saving and repository loading.
